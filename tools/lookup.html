Song lookup

Reads PraiseCharts and gives you rows for songs.tsv. The Camelot value is not fetched: it is worked out from the key by the same code the app uses.

This page only works when served by npm run lookup on your own machine. Opened any other way, the lookups cannot run.

A name and artist together works well enough most of the time. When the wrong song comes back, find it on PraiseCharts yourself and paste its address instead: that skips the search, so there is nothing left to guess.
